# FICHAS TECNICAS DA ZIRA - rascunho
#
# COMO LER ESTE ARQUIVO
#   Linha sem #  -> pronta para colar. Sao as embalagens, e eu tenho certeza delas:
#                   um copo de 300ml gasta um copo de 300ml, uma tampa e uma colher.
#   Linha com #  -> FALTA A QUANTIDADE. O cardapio impresso diz o QUE vai no produto,
#                   mas nao diz QUANTO. So a Zira sabe. Preencha o "?" e tire o #.
#
# ONDE COLAR: Produtos -> "Importar fichas tecnicas (lista)" -> Conferir -> Gravar fichas.
#
# A QUANTIDADE E PARA UMA UNIDADE DO PRODUTO, na unidade do insumo:
#   polpa em kg (0,3 = 300 gramas)   |   copo, tampa, colher em peca (1)
#
# CUIDADO: gravar SUBSTITUI a ficha inteira do produto. Hoje nenhum produto tem ficha,
# entao nao ha o que perder - mas na segunda vez, a lista precisa vir completa.
#
# DEPOIS DE GRAVAR: o produto fica ESGOTADO no cardapio enquanto qualquer insumo da ficha
# estiver zerado. Lance a contagem em Estoque ANTES de gravar as fichas.
# ============================================================================
